# Future Architecture: Deep Learning Integration

This document outlines the strategic plan to upgrade the CV pipeline from the SIFT baseline to state-of-the-art Deep Learning models.

## Current Baseline (SIFT)
The pipeline currently utilizes OpenCV's SIFT (Scale-Invariant Feature Transform) inside xtractor.py and matcher.py. 
* **Pros:** Fast, CPU-bound, deterministic, great for testing backend API plumbing.
* **Cons:** Struggles with extreme lighting variance and scale differences common in lunar imagery.

## Upgrade Path: LoFTR / SuperGlue
For the final production deployment, the CV engine will be swapped to a transformer-based feature matcher (e.g., SuperGlue or LoFTR).

### Implementation Steps
1. **Fine-Tuning:** Utilize the 512x512 .npz dataset generated by generate_full_dataset.py to fine-tune a pre-trained LoFTR model on Lightning Studio (H200 GPUs). This adapts the model to the harsh shadows of lunar craters.
2. **Backend Swap:** 
   * Modify ackend/pipeline/cv_pipeline/extractor.py to load the .pt PyTorch model weights.
   * Modify ackend/pipeline/cv_pipeline/matcher.py to run model inference instead of cv2.FlannBasedMatcher.
3. **API Contract:** The input (image arrays) and output (Homography Matrix & Inliers) will remain identical, meaning the FastAPI dashboard requires zero code changes.
